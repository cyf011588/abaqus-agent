## P1 长期路线（只规划，不实施）

1. **异步作业**：`submit_job` 改后台提交 + 轮询节点，支持超时与取消（小时级作业刚需）。
2. **短期记忆升级**：LangGraph `SqliteSaver` checkpointer 接管会话状态，替代手动 history；对 `submit_job`、`remove_skill` 等高危工具加 `interrupt` 人审。

6. **deerflow 源码研读**：借鉴其多 agent 分工与上下文工程，用于第 3 条重构。
7. **简历 skill**：在事实库扩展到全部求职项目后，调教一个「输入 JD + 事实库 → 输出定制简历」的本地 skill。
