# 通用建模 Skill —— 无相似案例时怎么从零建

> **定位**：14 个内置案例之外的任意结构，让 LLM 用"Abaqus 的基本理解"从零建，而不是拒绝或硬套案例。
> **实现**：`agent/modeling_knowledge.py`（知识）+ `plan_model` / `modeling_guide` / `write_inp` / `mesh_inp` / `append_inp`（工具）+ 本文档（流程约束）。

---

## 一、决策顺序（先便宜后贵）

1. **match_case**：用需求关键词匹配 14 个内置案例。
   - 命中 ≥2 → **改造最像的案例**（改尺寸/材料/边界），不要从零重写。
   - 命中 <2 → 进入第 2 步。
2. **通用知识**：`modeling_guide` 按主题取章节（unit / material / section / step / bc / load / mesh / recipe）。
3. **仍然不确定** → `web_search`（`Abaqus <关键字> <结构> example`），例如：
   - `Abaqus shell buckling *Buckle keyword example`
   - `Abaqus contact pair *Contact Property friction keyword`
4. **绝不编造**：材料参数、几何尺寸、边界条件，只要用户没给、知识库也没有，就**问用户**，不要凭感觉填数字。

---

## 二、十步范式（MODEL_RECIPE，每步关键字与陷阱）

| 步 | 做什么 | 核心关键字 | 常见陷阱 |
|---|---|---|---|
| 1 部件 | 草绘/拉伸/旋转建几何 | `*Part`、`*Node`、`*Element` | 2D 必须 z=0 且用 2D 单元；实体不能是空壳 |
| 2 材料 | 弹性/塑性/热 | `*Material`、`*Elastic`、`*Plastic`、`*Conductivity` | 单位自洽；`*Plastic` 第一行必须是「屈服应力, 0.」 |
| 3 截面 | 壳厚度 / 梁截面 / 实体 | `*Shell Section`、`*Beam Section`、`*Solid Section` | 壳厚度与几何厚度一致；壳法向朝外 |
| 4 装配 | 实例 + 定位 | `*Assembly`、`*Instance` | 平移/旋转写对；装配无重叠穿透 |
| 5 分析步 | Static / Modal / Buckle / Heat | `*Step`、`*Static`、`*Frequency`、`*Buckle`、`*Heat Transfer` | 大变形开 `nlgeom=ON`；非线性步给足够增量 |
| 6 相互作用 | 接触 / 绑定 / 耦合 | `*Contact`、`*Tie`、`*Coupling` | 主从面不交叉；接触必须有摩擦属性（否则静默无摩擦） |
| 7 边界 | 固支 / 简支 / 对称 | `*Boundary` | 用**最小约束集**，不要"整面全固定"糊过去 |
| 8 载荷 | 力 / 压强 / 位移 | `*Cload`、`*Dload`、`*Dsload` | **位移也是载荷**（`*Boundary` 带非零值），方向沿自由度 |
| 9 网格 | 单元划分 | 单元类型 + 种子 | 单元类型必须与几何匹配（S4R 壳 / C3D8R 实体 / B31 梁） |
| 10 作业 | 提交 | `*Job`、`*End Step` | 收敛失败先查接触/边界/材料 |

## 三、单元选择速查（UNIT_GUIDE）

| 结构特征 | 推荐单元 | 说明 |
|---|---|---|
| 三维实体 | C3D8R / C3D8 / C3D20R | C3D8R 减缩积分防沙漏；C3D8 全积分但弯剪偏刚 |
| 薄壁/板/壳 | S4R / S4 | S4R 通用减缩积分，注意厚度与法向 |
| 梁/柱/框架（看内力） | B31 / B32 | 节点共享即刚接 |
| 桁架/拉压杆 | T3D2 | 只受轴力，铰接 |
| 平面应变 | CPE4 / CPE4R | 轴向应变为零的截面 |
| 平面应力 | CPS4 / CPS4R | 薄板面内受力 |
| 轴对称 | CAX4 / CAX4R | x=r 径向、y=z 轴向 |
| 热传导 | DC2D4 / DC3D8 | 温度自由度 11 |

## 四、与用户交互（"建模助手"不是"命令执行器"）

1. **收到"建一个 XX"**：
   - 先 `plan_model(requirement)`，输出 6 项草案：部件/材料/单元/分析步/边界/载荷。
   - **缺失项必须问**：几何尺寸、材料等级、是否大变形、边界是固支还是简支、载荷大小与方向。
   - **不确认不写 inp**——改一次 inp 比问一句贵得多。
2. **确认后**：
   - `write_inp`（或最像案例的 build 脚本 + 参数覆盖）。
   - `mesh_inp`（网格密度/单元类型）。
   - 每写一段 `read_text` 回读关键字自检。
3. **交付**：3D 预览（边界 + 载荷位置自动渲染）+ 关键字清单 + 验收结论。

---

## 五、验收清单（写完 inp 必过）

- [ ] 部件几何闭合、2D/3D 单元与几何匹配
- [ ] 材料单位自洽（mm-N-MPa 或 m-N-Pa）；`*Plastic` 首行「屈服应力, 0」
- [ ] 截面厚度/偏置正确，壳法向朝外
- [ ] 装配无重叠/穿透
- [ ] 分析步 `nlgeom` 与实际一致（大变形？）
- [ ] 接触对主从面不交叉、有摩擦
- [ ] 边界是最小约束集（不是"全固定"）
- [ ] 载荷类型正确（力 = Cload/Dload，位移 = Boundary 带值）
- [ ] 单元类型与几何匹配（S4R / C3D8R / B31）
- [ ] 节点/单元数合理，无零长度单元
