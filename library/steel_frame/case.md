# 平面纯钢框架（Steel Frame）

## 一句话
B31 梁单元搭出多层多跨平面钢框架：柱、梁在节点处刚接（共享节点），柱底铰接，楼层施加竖向荷载——从单构件迈向结构体系的第一个案例。

## 建模过程（怎么做）
1. 生成规则节点网：`(n_story+1) × (n_bay+1)` 个节点，坐标 `(col·L, story·h, 0)`。
2. 柱单元（竖直，story 层 col 列）+ 梁单元（水平，每层楼面 col 跨），全部用 B31。
3. 柱用 `COLS`、梁用 `BEAMS` 两个 elset，分别给矩形截面（`*Beam Section, section=RECT` + 截面方向）。
4. 梁柱共享节点即刚接；柱底 `BASE` 约束 U1/U2（铰接）。
5. 平面框架出平面约束：所有节点 U3=0、R1=R2=0（只允许平面内弯曲 R3）。
6. 楼层节点 `FLOORS` 施加竖向集中力 `-P`（模拟楼面荷载）。

## 原理（为什么）
- 框架抗侧刚度来自梁柱节点刚接：梁端弯矩约束柱的侧移，形成整体抗侧体系（纯铰接会退化为机构）。
- B31（Timoshenko 梁）单段即可精确描述受弯，共享节点天然实现刚接，无需额外约束方程。
- 柱底铰接（只约束平动、放开转动）是最常见的钢框架支座简化。

## 参数
| 参数 | 含义 | 默认 |
|---|---|---|
| n_story / n_bay | 层数 / 跨数 | 2 / 2 |
| h / L | 层高 / 跨度 | 3000 / 6000 |
| b_col / d_col | 柱截面宽 / 高 | 200 / 200 |
| b_beam / d_beam | 梁截面宽 / 高 | 200 / 300 |
| E / nu | 弹性模量 / 泊松比 | 210000 / 0.3 |
| P | 每层每节点竖向荷载 | 100000 |

## 适用场景
- 纯钢框架 / 门式刚架 / 多层框架的静力分析；
- 作为「对话式建模」的骨架案例：改层数、跨数、层高、截面、荷载即可生成不同框架。

## 生成命令
```bash
python build_inp.py --n-story 2 --n-bay 2 --h 3000 --L 6000 --P 100000 --job FRAME --out DIR
```
