# 两方块面面接触（Contact Pair）

## 一句话
C3D8R 体单元 + `*Contact Pair`，上下两个方块沿 z 叠放、顶面压缩，演示面面接触与摩擦——接触非线性分析的入门算例。

## 建模过程（怎么做）
1. 两个相同方块沿 z 堆叠：下块 z∈[0,W]，上块 z∈[W,2W]（`hex_mesh` 的 origin 偏移）。
2. 下块顶面建 `BOT_TOP`（S2 面）、上块底面建 `TOP_BOT`（S1 面），两套节点在 z=W 重合。
3. `*Surface Interaction` 定义摩擦 `mu`，`*Contact Pair` 把主/从面配对。
4. 下块底面 `BASE` 全约束，上块顶面 `TOP` 施加压缩位移 `-d`。
5. `*Step, nlgeom=YES`（接触需几何非线性），静力分析。

## 原理（为什么）
- 接触是强非线性：法向不可穿透（罚函数/拉格朗日）、切向摩擦（库仑），求解需迭代。
- 主面（S2，下块顶面）与从面（S1，上块底面）配对；主从面选择影响收敛。
- `nlgeom=YES` 开启大位移，是接触问题收敛的常见必要条件。

## 参数
| 参数 | 含义 | 默认 |
|---|---|---|
| W | 方块边长 | 10 |
| E / nu | 弹性模量 / 泊松比 | 210000 / 0.3 |
| d | 压缩位移 | 0.1 |
| mu | 摩擦系数 | 0.2 |
| nx / ny / nz | 三向网格数 | 4 / 4 / 4 |

## 适用场景
- 螺栓连接、拼装构件、压痕/接触传力的基础；
- 接触收敛性调试的教学起点。

## 生成命令
```bash
python build_inp.py --W 10 --d 0.1 --mu 0.2 --nx 4 --ny 4 --nz 4 --job CONTACT --out DIR
```
