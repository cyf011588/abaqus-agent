# 平板稳态热传导（Heat Slab）

## 一句话
DC2D4 热传导单元，平板两端固定温度，求解稳态温度场——与傅里叶定律对照的热分析入门算例。

## 建模过程（怎么做）
1. 矩形网格离散平板（`nx × ny` 个 DC2D4）。
2. 材料给 `*Conductivity`（导热系数 k），热单元无需截面。
3. `*Heat Transfer, steady state` 稳态分析步。
4. 左端 `LEFT` 固定温度 T1、右端 `RIGHT` 固定温度 T2（温度自由度 11）。

## 原理（为什么）
- 傅里叶定律：`q = −k·dT/dx`，一维稳态下温度线性分布，热流 `q = k·(T1−T2)/L`。
- 稳态热传导无需初始温度与比热，只需边界温度（或热流/对流）。
- 温度自由度编号为 11（Abaqus 约定），与位移自由度（1~6）分开。

## 参数
| 参数 | 含义 | 默认 |
|---|---|---|
| L / H | 板长 / 板高 | 100 / 20 |
| k | 导热系数 | 50 |
| T1 / T2 | 左端 / 右端温度 | 100 / 20 |
| nx / ny | 长度 / 高度网格数 | 20 / 4 |

## 适用场景
- 稳态导热、墙体保温、热桥等热分析基础；
- 演示 2D 热单元与温度边界。

## 生成命令
```bash
python build_inp.py --L 100 --H 20 --k 50 --T1 100 --T2 20 --job HEAT --out DIR
```
