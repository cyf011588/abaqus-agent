# 带孔方板弹塑性拉伸（Elastoplastic Plate with Hole）

## 一句话
S4R 壳单元 + `*Plastic`（Mises 屈服 + 线性硬化），带孔方板两端拉伸，观察孔边应力集中处的塑性屈服。

## 建模过程（怎么做）
1. 复用带孔方板映射网格（孔边径向加密、外边界方形），`nr × nt` 个 S4R 单元。
2. 左 / 右边界施加对称拉伸位移 `±u`，左边界同时约束 y 防刚体。
3. 材料在 `*Elastic` 之外增加 `*Plastic`：屈服应力 `yield_stress`（塑性应变 0），后续硬化点 `(hard_stress, hard_pe)`。
4. 建 `*Static` 分析步（位移足够大时孔边进入塑性）。

## 原理（为什么）
- Mises 屈服准则：当等效应力达到屈服应力时材料进入塑性，超过屈服后按硬化曲线流动。
- 孔边应力集中（弹性 Kt≈3）使孔边最先达到屈服应力，形成塑性区；随载荷增大塑性区扩展。
- `*Plastic` 第一行必须是 `屈服应力, 0.`，后续行为应力-塑性应变对（硬化段）。

## 参数
| 参数 | 含义 | 默认 |
|---|---|---|
| W / H / r / t | 板宽 / 板高 / 孔半径 / 板厚 | 200 / 100 / 20 / 2 |
| E / nu | 弹性模量 / 泊松比 | 210000 / 0.3 |
| yield_stress | 屈服应力 | 235 |
| hard_stress / hard_pe | 硬化点应力 / 塑性应变 | 300 / 0.05 |
| u | 端部对称拉伸位移 | 2.0 |
| nr / nt | 径向 / 环向网格数 | 12 / 48 |

## 适用场景
- 材料非线性分析入门；
- 孔口 / 缺口处的应力集中与塑性区演化评估。

## 生成命令
```bash
python build_inp.py --W 200 --H 100 --r 20 --yield-stress 235 --u 2 --job PLASTIC --out DIR
```
