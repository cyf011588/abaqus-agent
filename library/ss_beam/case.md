# 简支梁（Simply Supported Beam）

## 一句话
B31 梁单元（二节点空间 Timoshenko 梁），两端简支、跨中集中力，看挠度与弯矩——梁理论的入门算例。

## 建模过程（怎么做）
1. 沿梁长离散为 `nx` 个 B31 单元，节点沿 x 轴均匀分布（只建中性轴线模型）。
2. 左端 `LEFT` 约束 1~3 自由度（铰支座），右端 `RIGHT` 约束 2~3（滚动支座，允许轴向伸缩）。
3. 跨中 `MID` 施加 -y 向集中力 `P`。
4. `*Beam Section` 指定矩形截面 `b×h` 与截面方向 `n1=(0,1,0)`。
5. 建 `*Static` 分析步，输出 U / S / E。

## 原理（为什么）
- 跨中集中力下简支梁跨中挠度解析解：`δ = P·L³ / (48·E·I)`，矩形截面 `I = b·h³ / 12`。
- B31 是剪切变形梁（Timoshenko），深梁或短跨时与欧拉梁略有差异。
- 梁单元只需建「线」模型，截面由 `*Beam Section` 描述，网格量远小于体单元。

## 参数
| 参数 | 含义 | 默认 |
|---|---|---|
| L | 梁跨 | 1000 |
| b / h | 矩形截面宽 / 高 | 20 / 40 |
| E / nu | 弹性模量 / 泊松比 | 210000 / 0.3 |
| P | 跨中集中力 | 1000 |
| nx | 长度方向网格数 | 20 |

## 适用场景
- 梁 / 框架结构概念设计阶段快速校核；
- 对比梁单元与体单元结果，验证单元选择。

## 生成命令
```bash
python build_inp.py --L 1000 --b 20 --h 40 --P 1000 --nx 20 --job SSB --out DIR
```
