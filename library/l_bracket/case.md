# L 型支架（L-Bracket）

## 一句话
S4R 壳单元，竖直板 + 水平板两块在转角边共享节点，一面固定、另一面自由端受载，考察转角处的弯矩传递与应力集中。

## 建模过程（怎么做）
1. 竖直板（`x∈[0,t]`、`y∈[0,H]`）与水平板（`x∈[t,L]`、`y∈[0,t]`）分别生成规则壳网格。
2. 两块板在转角边 `x=t, y∈[0,t]` 共享节点（坐标去重），实现刚性连续连接，避免重叠或缝隙。
3. 竖直板底部建 `FIXED` 节点集，约束 1~6 自由度（完全固定）。
4. 水平板自由端（x=L）建 `TIP` 节点集，施加 -y 向载荷（总力均分到端边节点）。
5. 定义 `*Shell Section`（厚度 thk）与材料 `STEEL`，建 `*Static` 分析步。

## 原理（为什么）
- L 形连接件靠转角处传递弯矩，载荷偏心产生弯曲应力，转角内角处应力集中最明显。
- 用「共享节点」而非重合网格，保证两板位移连续、不产生虚假重叠或缝隙。
- 壳单元中面建模，厚度由 `*Shell Section` 给定，板厚变化只需改 thk 而无需重划网格。

## 参数
| 参数 | 含义 | 默认 |
|---|---|---|
| H / L | 竖直臂高 / 水平臂长 | 100 / 100 |
| t | 臂宽（厚度方向） | 20 |
| thk | 板厚（壳 section） | 5 |
| E / nu | 弹性模量 / 泊松比 | 210000 / 0.3 |
| P | 自由端总载荷 | 1000 |
| nx1 / my / nx2 | 臂宽 / 竖直臂 / 水平臂网格数 | 4 / 20 / 16 |

## 适用场景
- 支架、托架、角连接件等 L 形薄壁结构；
- 演示多块板「共享边」组装与网格对齐（对应复杂结构里子部件拼装的思路）。

## 生成命令
```bash
python build_inp.py --H 100 --L 100 --t 20 --thk 5 --nx1 4 --my 20 --nx2 16 --job LB --out DIR
```
