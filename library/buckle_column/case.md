# 受压柱线性屈曲（Column Buckling）

## 一句话
C3D8R 体单元 + `*Buckle` 摄动分析步，细长柱一端固定、一端轴向受压，求屈曲特征值与临界载荷——稳定分析的入门算例。

## 建模过程（怎么做）
1. 规则六面体网格离散细长柱（`nx × ny × nz` 个 C3D8R，长度方向网格加密）。
2. 一端（x=0）建 `FIXED` 约束 1~3，另一端（x=L）建 `TIP` 施加轴向参考压力 `P`。
3. 建 `*Step, perturbation` + `*Buckle, eigensolver=Lanczos`，提取前 `nmodes` 阶。
4. 屈曲特征值 = 临界载荷因子，实际临界载荷 = 因子 × 参考载荷 P。

## 原理（为什么）
- 欧拉柱屈曲临界载荷：`Pcr = π²·E·I / (μ·L)²`，一端固定一端自由 `μ = 2`，即 `Pcr = π²·E·I / (4·L²)`。
- 线性屈曲是特征值问题：刚度矩阵在参考载荷下的几何刚度使系统奇异，最小特征值对应一阶屈曲。
- 屈曲与强度失效不同：细长柱往往在应力远低于屈服时就发生失稳，故需单独做稳定校核。

## 参数
| 参数 | 含义 | 默认 |
|---|---|---|
| L / W / H | 柱长 / 截面宽 / 截面高 | 1000 / 20 / 20 |
| E / nu | 弹性模量 / 泊松比 | 210000 / 0.3 |
| P | 参考轴向压力 | 1 |
| nmodes | 屈曲模态阶数 | 4 |
| nx / ny / nz | 长度 / 截面两向网格数 | 40 / 2 / 2 |

## 适用场景
- 柱、压杆等受压构件的稳定校核；
- 为初始缺陷（imperfection）分析提供屈曲模态。

## 生成命令
```bash
python build_inp.py --L 1000 --W 20 --H 20 --P 1 --nmodes 4 --nx 40 --job BUCKLE --out DIR
```
