# 轴对称圆盘轴向压缩（Axisymmetric Disc）

## 一句话
CAX4 轴对称单元，实心圆盘顶部受压，利用轴对称把三维问题降为二维——轴对称分析入门算例。

## 建模过程（怎么做）
1. 矩形截面（径向 r × 轴向 z）映射网格，`nx × ny` 个 CAX4。
2. CAX4 约定：x 坐标 = 径向 r，y 坐标 = 轴向 z。
3. 对称轴（r=0，`AXIS`）约束 U1（径向位移为 0），底面 `BASE` 约束 U2。
4. 顶面建 `*Surface`（S3 边），`*Dload` 施加均匀压力 `p`。

## 原理（为什么）
- 轴对称问题：几何、载荷、边界都绕中心轴旋转对称，位移/应力与环向角无关，可只用 r-z 平面建模。
- 对称轴 r=0 处径向位移必为 0（几何奇点），须约束 U1。
- 与平面应变不同，轴对称隐含了环向（hoop）应力，单元刚度自动计入。

## 参数
| 参数 | 含义 | 默认 |
|---|---|---|
| r1 | 圆盘半径 | 50 |
| H | 圆盘厚度（轴向） | 20 |
| E / nu | 弹性模量 / 泊松比 | 210000 / 0.3 |
| p | 顶部压力 | 10 |
| nx / ny | 径向 / 轴向网格数 | 20 / 8 |

## 适用场景
- 圆盘、圆柱、压力容器封头等旋转体的应力分析；
- 演示轴对称降维与对称轴约束。

## 生成命令
```bash
python build_inp.py --r1 50 --H 20 --p 10 --nx 20 --ny 8 --job AXISYM --out DIR
```
