# 悬臂梁模态分析（Modal Analysis）

## 一句话
C3D8R 体单元 + `*Frequency` 摄动分析步，提取悬臂梁前 N 阶固有频率与振型——动力学入门算例。

## 建模过程（怎么做）
1. 复用悬臂梁规则六面体网格（`nx × ny × nz` 个 C3D8R 单元）。
2. 一端（x=0 面）建 `FIXED` 节点集，约束 1~3 自由度（固定端）。
3. 材料在 `*Elastic` 之外增加 `*Density`（密度 rho，模态分析必须有质量）。
4. 建 `*Step, perturbation` + `*Frequency, eigensolver=Lanczos`，提取前 `nmodes` 阶。
5. 输出位移 U（振型）。

## 原理（为什么）
- 悬臂梁一阶固有频率解析解：`f1 = (1.875² / 2π) · √(E·I / (ρ·A·L⁴))`，`I = W·H³/12`，`A = W·H`。
- 模态分析是线弹性特征值问题，与载荷无关，只取决于刚度与质量分布；固定端约束是边界条件。
- 单位须自洽：E 取 MPa、长度取 mm、密度取 t/mm³（钢 ≈ 7.85e-09）。

## 参数
| 参数 | 含义 | 默认 |
|---|---|---|
| L / W / H | 梁长 / 宽 / 高 | 100 / 10 / 10 |
| E / nu | 弹性模量 / 泊松比 | 210000 / 0.3 |
| rho | 密度（t/mm³） | 7.85e-09 |
| nmodes | 提取模态阶数 | 6 |
| nx / ny / nz | 三方向网格数 | 20 / 2 / 2 |

## 适用场景
- 结构固有频率与振型评估、避免共振；
- 作为动力学分析（谐响应 / 瞬态）的前置模态提取。

## 生成命令
```bash
python build_inp.py --L 100 --W 10 --H 10 --rho 7.85e-09 --nmodes 6 --job MODAL --out DIR
```
