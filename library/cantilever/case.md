# 悬臂梁（Cantilever Beam）

## 一句话
C3D8R 体单元，一端固定、自由端施加集中力，看挠度与应力分布。有限元入门最经典的算例，用于验证网格收敛并与解析解对照。

## 建模过程（怎么做）
1. 规则六面体网格：把梁离散为 `nx × ny × nz` 个 C3D8R 单元（八节点六面体减缩积分）。
2. 一端（x=0 面）建 `FIXED` 节点集，约束 1~3 自由度（完全固定）。
3. 自由端（x=L 面）建 `TIP` 节点集，施加 -z 向集中力，总力 `P` 均分到端面每个节点。
4. 定义材料 `STEEL`（弹性模量 E、泊松比 nu）与 `*Solid Section`。
5. 建 `*Static` 分析步，输出位移 U、应力 S、应变 E。

## 原理（为什么）
- 悬臂梁自由端挠度解析解：`δ = P·L³ / (3·E·I)`，矩形截面惯性矩 `I = W·H³ / 12`。
- C3D8R 减缩积分可避免体积自锁，但弯曲问题需要足够网格密度（高度方向至少 2~4 层）。
- 固定端到自由端的弯矩线性递减，最大应力出现在固定端上下表面。

## 参数
| 参数 | 含义 | 默认 |
|---|---|---|
| L / W / H | 梁长 / 宽 / 高 | 100 / 10 / 10 |
| E / nu | 弹性模量 / 泊松比 | 210000 / 0.3 |
| P | 自由端总载荷 | 1000 |
| nx / ny / nz | 三方向网格数 | 20 / 2 / 2 |

## 适用场景
- 验证网格收敛性与单元选择；
- 作为「最小可行 inp」模板，扩展成更复杂的梁 / 受弯构件。

## 生成命令
```bash
python build_inp.py --L 100 --W 10 --H 10 --P 1000 --nx 20 --ny 2 --nz 2 --job CANT --out DIR
```
