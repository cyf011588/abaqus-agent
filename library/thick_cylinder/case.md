# 平面应变厚壁圆筒（Thick Cylinder, Plane Strain）

## 一句话
CPE4 平面应变单元，1/4 圆环截面受均匀内压，看环向/径向应力分布——与 Lame 解析解对照的经典算例。

## 建模过程（怎么做）
1. 取第一象限 1/4 圆环（内径 a、外径 b），用极坐标网格离散为 `nr × nt` 个 CPE4 单元。
2. 利用对称性：`SYMX`（θ=0，x 轴）约束 U2、`SYMY`（θ=π/2，y 轴）约束 U1。
3. 内壁（r=a）建 `*Surface`（单元 S4 边），用 `*Dload` 施加均匀内压 `p`。
4. `*Solid Section` 给平面应变厚度 1，材料 `STEEL`，建 `*Static` 分析步。

## 原理（为什么）
- Lame 解（平面应变厚壁圆筒内压）：
  - 环向应力 `σθ = p·a²/(b²−a²) · (1 + b²/r²)`
  - 径向应力 `σr = p·a²/(b²−a²) · (1 − b²/r²)`
  - 内壁 r=a 处环向应力最大：`σθ,max = p·(a²+b²)/(b²−a²)`
- 平面应变假设：轴向（z）应变为零，适用于沿轴向很长、受均匀内压的圆筒中段。
- 用 1/4 模型 + 对称边界，显著减小网格规模。

## 参数
| 参数 | 含义 | 默认 |
|---|---|---|
| a / b | 内径 / 外径 | 100 / 200 |
| p | 内压 | 10 |
| E / nu | 弹性模量 / 泊松比 | 210000 / 0.3 |
| nr / nt | 径向层数 / 环向段数 | 8 / 12 |

## 适用场景
- 压力容器、管道等承受内压构件的应力校核；
- 演示 2D 平面应变建模与对称边界。

## 生成命令
```bash
python build_inp.py --a 100 --b 200 --p 10 --nr 8 --nt 12 --job CYL --out DIR
```
