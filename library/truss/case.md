# 平面三角桁架（Triangular Truss）

## 一句话
T3D2 桁架单元（二节点，只传轴力），等腰三角形桁架、两铰支座、顶点集中力——静定桁架的入门算例。

## 建模过程（怎么做）
1. 建 3 个节点：`A(0,0)`、`B(L,0)`、`C(L/2,H)`，组成等腰三角形。
2. 用 3 根 T3D2 杆连接 A-B（下弦）、A-C、B-C（两根斜杆）。
3. `A` 约束 1~3（铰支座），`B` 约束 2（滚动支座，只限制 y）。
4. 顶点 `C` 施加 -y 集中力 `P`。
5. `*Solid Section` 指定杆截面积 `area`，材料 `STEEL`，建 `*Static` 分析步。

## 原理（为什么）
- 静定三角桁架可用节点法 / 截面法解析求各杆轴力（两根斜杆受压、下弦受拉，对称结构斜杆轴力相等）。
- T3D2 只传轴力、不传弯矩，适合桁架（杆端铰接）的理想化。
- 桁架单元只需截面面积，无需截面形状，网格为线单元。

## 参数
| 参数 | 含义 | 默认 |
|---|---|---|
| L / H | 底边跨 / 顶点高 | 1000 / 500 |
| area | 杆截面积 | 100 |
| E / nu | 弹性模量 / 泊松比 | 210000 / 0.3 |
| P | 顶点集中力 | 1000 |

## 适用场景
- 桁架 / 屋架 / 塔架的概念验证；
- 演示「杆端铰接 + 只传轴力」的理想化建模。

## 生成命令
```bash
python build_inp.py --L 1000 --H 500 --area 100 --P 1000 --job TRUSS --out DIR
```
