# 带孔方板拉伸（Plate with Hole）

## 一句话
S4R 壳单元，方形板中心开圆孔，两端对称拉伸，观察孔边应力集中（Stress Concentration）。

## 建模过程（怎么做）
1. 映射网格：从孔边界（内圈）向外边界（方板边缘）做径向分层，环向均匀分段，形成 `nr × nt` 个 S4R 单元。
2. 孔边界沿径向加密、外边界落在方形轮廓上（射线与矩形边求交得到外圈点）。
3. 左边界 `LEFT`、右边界 `RIGHT` 分别施加对称位移 `±u`（x 向拉伸），左边界同时约束 y 防止刚体平动。
4. 定义 `*Shell Section`（厚度 t）与材料 `STEEL`，建 `*Static` 分析步。

## 原理（为什么）
- 无限大板受单轴拉伸、中心圆孔的应力集中系数 `Kt = σmax / σnom ≈ 3`（经典弹性力学解）。
- 有限板宽会提高 Kt：孔径与板宽之比越大，Kt 越高，孔边网格需加密才能准确捕捉峰值。
- 用位移加载（±u）比直接加力更易收敛，且便于对称施加。

## 参数
| 参数 | 含义 | 默认 |
|---|---|---|
| W / H | 板宽（x）/ 板高（y） | 200 / 100 |
| r | 孔半径 | 20 |
| t | 板厚（壳） | 2 |
| E / nu | 弹性模量 / 泊松比 | 210000 / 0.3 |
| u | 端部对称拉伸位移 | 0.5 |
| nr / nt | 径向层数 / 环向段数 | 12 / 48 |

## 适用场景
- 验证应力集中与网格收敛；
- 作为带孔 / 开洞构件的网格模板，扩展到多孔板。

## 生成命令
```bash
python build_inp.py --W 200 --H 100 --r 20 --t 2 --nr 12 --nt 48 --job PH --out DIR
```
